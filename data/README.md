# Data

This folder includes `EuroSAT.zip`, the compact dataset archive used for the RGB EuroSAT experiments.

Unzip before training:

```bash
unzip EuroSAT.zip -d .
```

The expanded `EuroSAT/` folder is intentionally ignored by Git because it contains many image files. Keep the zip for portability or replace this folder with documented download instructions if the repository should stay lightweight.
